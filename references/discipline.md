# 仓位纪律、纠错复盘与经典战法

## 一、仓位金字塔（仓位跟确定性走）

| 仓位层级 | 场景 | 仓位 |
|---|---|---|
| 试错仓 | 新周期启动首日/新题材首板 | 5%~10% |
| 确认仓 | 主线发酵，龙头首分歧低吸/弱转强确认 | 递进至 20%~30% |
| 主仓 | 高确定性主升期核心票二次加仓 | ≤50%，留回旋余地 |
| 空仓/迷你仓 | 退潮期、看不懂、无模式内机会 | 0 或 ≤5% |

**禁止动作**：满仓梭哈单只；被套后补仓摊成本（大亏根源）；浮盈盲目加仓（尤其超短）。
**集中度**：同时持仓 ≤2~3 只，资金集中最强核心，去弱留强。买 50 只的"超市战法"是伪分散，杜绝。

**动态降仓信号**：
- 连亏 2~3 笔 → 降到试错仓或强制空仓 3~5 天重置心态；
- 阶段回撤 -10%~-15% → 停止开新仓直至找回节奏；
- 情绪退潮 → 全线降仓或空仓。

## 二、盈亏比前置

潜在盈利 ÷ 潜在止损 **≥ 3:1** 才值得做（最少 2:1）。
选支撑位明确（止损空间小）+ 上方有空间（压力远）的票。
胜率 50% + 盈亏比 3:1 长期必盈利；胜率再高 + 盈亏比 1:1 长期必亏。

## 三、开仓前三问（防腰斩五问的精简版）

任一"否"或模棱两可 → 放弃交易、空仓观望：
1. 这笔交易完全在模式内吗？（拒绝分时好看/听消息/群喊单）
2. 当前情绪周期与板块梯队允许吗？（主升做分歧、高潮渐减仓、退潮死管手）
3. 做错了防守锚定点清晰吗？能无条件机械止损并接受亏损吗？（不知止损不推仓，不知防守不开仓）

## 四、防腰斩五问（开仓前完整自检）

1. 当前情绪周期允许重仓吗？（退潮 → 轻仓/空仓）
2. 模式内吗？有清晰买点/止损/锚定点吗？（否 → 放弃）
3. 是鱼尾行情吗？（中位补涨全红 + 龙头缩量加速 + 舆论狂热 = 是 → 不追，持仓减）
4. 仓位符合试错→确认递进吗？满仓梭哈？（是 → 禁止）
5. 若错了能止损且接受吗？（不能 → 不买）

## 五、四类错误与纠错

| 错误类型 | 表现 | 纠错动作 |
|---|---|---|
| 买错（模式外随手单） | 听消息/跟风/退潮接力中位 | 次日竞价或开盘无论输赢直接清仓；输得起手续费输不起深套；不补仓 |
| 卖错 | 恐高过早卖飞龙头；破锚因侥幸不舍得走（最严重违纪） | 卖飞：若再触发模式内买点（首次爆量分歧稳住/二波放量突破）允许极小仓位追回，绝不开陌生杂毛发泄；破锚：分时反抽不过均价线必须全清 |
| 节奏错 | 退潮期还在打接力板 | 当天立即停止一切新开仓，清理走弱持仓收回流动性 |
| 系统错 | 某子模式统计胜率 <30% 且盈亏比极差 | 立刻冻结该子模式，微调参数写入交易手册（先确认样本量 10~20 笔足够） |

心法："你可以买错、卖错、踏空，这都正常；唯一不能原谅的是明知错了还扛、还补仓、还骗自己会回来的。"

## 六、复盘 SOP（每日收盘 30~60 分钟，五步）

1. **涨停/跌停复盘**：涨停板归类题材、梳理身位梯队与连板高度、标记最早封板先锋；统计跌停家数与昨日涨停今日大面的核按钮数量 → 为情绪周期定位。
2. **持仓校验**：锚定点（5 日线/分歧日最低价/突破阳半分位）守住没？符合盘前预期吗？走弱伪强势股列入次日竞价优先清仓名单。
3. **异动扫描**：核心主线中军/人气老龙底部温和右侧堆量、逆势抗跌迹象 → 挑出明日盯盘目标。
4. **交易日志**：每笔是否模式内？盈亏根本原因（系统还是运气）？有无破锚扛单/踏空乱买违章？红灯标注。
5. **周期定性**：综合连板高度、梯队、跌停数定阶段，预告明日动作。

周/月复盘：统计模式内胜率、盈亏比、最大连亏、模式外亏损占比 → 模式外趋近 0；胜率+盈亏比可接受则微调参数，否则冻结审视。

## 七、与量化共存

- 量化特征：程序化高频、T+0 套利、秒撤单封单、追涨杀跌放大波动、日内网格套利。
- 策略是**利用而非对抗**：买分歧（量化砸盘恐慌回踩支撑有承接低吸），卖一致（量化扫货缩量加速时逢高分批减仓）。
- 避开收割区：不追早盘无换手高开秒板/直线脉冲（几秒内拉升 5%+）；不参与日内板块急速轮动末端；退潮期不做高换手热门首板。
- 顺向隔日套利：做模式内核心龙/先锋今日牢固封板+板块梯队 → 次日量化竞价给溢价，享受溢价出场。
- 心法：量化消灭无规则随手单和追涨杀跌，但消灭不了正期望系统交易。

## 八、避坑清单（高频错误 → 正确做法）

| 坑 | 正确做法 |
|---|---|
| 等多头排列完全形成才买（买点滞后） | 20 日线即将拐头或刚转向上初期介入 |
| 分散持仓买 50 只 | 同时 ≤2~3 只，资金集中最强核心 |
| 退潮期"抄底"老题材 | 空仓等冰点新启动，不抄底不接飞刀 |
| 该强不强（昨强板今平开低开）还扛 | 竞价或开盘速走，不幻想 |
| 高位利好出尽追高 | 利好日爆量长上影 = 跑不是买 |
| 把下跌中继当震仓低吸 | 退潮期急跌反抽多为下跌中继，不按震仓处理 |
| 听消息满仓、被套补仓、赚点就跑亏了死扛、连亏后报复交易 | 建立模式 → 读险恶信号 → 控制回撤 → 修心；用死板系统代替盘中情绪决策 |

## 九、人性四大死穴（盘面镜像）

| 死穴 | 盘面镜像 |
|---|---|
| 贪婪 | 怕踏空，高潮末端追缩量加速板（接鱼尾）高位站岗 |
| 恐惧 | 上升途中震仓洗盘割肉在地板上；真买点不敢出手 |
| 侥幸 | 破位不死心"再等等反弹""套住不卖不亏"，小亏变深套 |
| 锚定 | 死盯成本价"回本再卖"，错过止损时机 |

克服方法：买卖点/仓位/止损提前写在纸上，触发即机械执行；大赚不膨胀、大亏不报复性交易；模式外"错过"是合理成本，模式外"做了"是系统漏洞。

## 十、三大经典战法

### 1. 520 战法（短线均线战法）
- 5 日线 = 攻击线（短期情绪资金动向）；20 日线 = 生命线（中期趋势，过去一月持仓者平均成本）。
- 买入 = 5 日线上穿 20 日线金叉；卖出 = 5 日线下穿 20 日线死叉。
- 辨真伪：20 日线必须向上或走平，向下时的金叉多为假信号；真买点 = 金叉次日收阳线且收盘价高于金叉当日，否则放弃。
- 量价配合：上穿 20 日线必须放量，回调必须缩量。
- 回踩加仓：站上 20 日线后 5 日线回踩 20 日线不破、再次拐头向上 = 加仓信号。
- 止损止盈：有效跌破 5 日线减半仓，有效跌破 20 日线清仓；短线思维持股不超 5 个交易日，目标涨幅 2%~5% 止盈。

### 2. 老太太扶楼梯战法（被套自救做 T）
- 核心：被套后利用下跌波动，每日开盘卖出、盘中低位接回赚差价，每天降 1%~2% 成本积累减亏。
- 触发（"5V10"）：连跌 5 个交易日或跌幅超 10%，排除基本面严重问题的高位股。
- 五日循环：第 1~3 日机械做 T（早盘竞价/开盘即卖出，盘中跌至 -3%~-5% 相对低位接回）；第 4~5 日择机格局（高开或转强先观望，冲高至成本线附近先卖一半锁利润，仍低开弱势继续先卖后买）。
- 细节：常规先 S 后 B 做倒 T，急跌机会可先 B 后 S 做正 T；执行果断，卖飞或买早都正常，长期平均有差价即可；目的是解套非暴富。
- **风险提示**：属左侧交易，单边下跌或流动性枯竭个股上风险极高，可能越做 T 亏得越多。

### 3. 圆弧底 75A 战法（中线底部反转）
- 定义：经典圆弧底 + 75 日均线确认（75 日线介于季线与 90 日线之间，站上则强、跌破则弱）。
- 形态：K 线呈锅底状，左半部下跌缓跌、底部长时间横盘、右半部缓慢爬升，多为小阴小阳；成交量左缩、底部极度缩量、右半部温和放大呈圆弧；形成时间 >3 个月更可靠；75 日线逐步走平并向上拐头。
- 四步操作：① 识别形态（左侧潜伏）；② 等待突破：放量突破颈线位（右半部高点）且有效站上 75 日线，突破必须放量（倍量更佳），无量突破多为假信号；③ 介入：激进 = 右半部小幅爬升+温和放量轻仓；稳健 = 放量突破颈线+站上 75 日线；回踩 = 突破后缩量回踩颈线或 75 日线两日不破；④ 目标与防守：目标涨幅 = 颈线价 - 圆弧底最低价（保守 30%~50%）；止损 = 跌破圆弧底最低价或有效跌破 75 日线。
- 注意：介入时短期均线最好多头排列；上升趋势初期成功率更高；分批买入不一次满仓。
