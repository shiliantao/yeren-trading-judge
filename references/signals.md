# 技术识别与买卖点系统

## 一、主力操盘四阶段（同一张 K 线，阶段不同意义相反）

| 阶段 | 特征 | 操作 |
|---|---|---|
| 建仓吸筹 | 长期阴跌后小阴小阳横盘，低点缓慢抬高，下跌缩量 | 不急介入，放自选跟踪；建仓末期突破启动节点（首板/反包阳）轻仓 5%~10% 试错，防守 = 突破阳最低价 |
| 洗盘/震仓 | 成本区震荡 3~5 天；主升途中日内振幅突增至 8%+；长下影/十字星；量能略放大或持平非暴量 | 黄金低吸点：持仓者锁仓，场外轻仓低吸；防守 = 震仓低点 |
| 主升拉升 | 连续新高多头排列；中后期缩量加速板；上涨放量、回落缩量 | 沿 5/10 日线锁仓；首次爆量分歧日二次上车；破 5 日线减、破分歧日低走 |
| 出货派发 | 高位放量滞涨；长上影/墓碑线/高开低走大阴；历史天量量顶天价不涨 | 坚决规避；持仓者分批清仓，不幻想二波重仓 |

## 二、震仓 vs 出货六维度（洗盘拿住、出货快跑）

| 维度 | 震仓（持有/低吸） | 出货（离场） |
|---|---|---|
| 位置 | 主升途中/突破前高前 | 高位爆量滞涨区 |
| 分时 | 急杀 -3%~-6% 有承接，迅速拉回均价线，不跟随新低 | 持续大单砸，均价随新低，反抽无力 |
| K 线 | 长下影/阴阳十字星/烂板但不破关键位 | 高位墓碑线，跌破关键均线，无量反抽 |
| 量能 | 略放量或平量，次日快速缩量反包 | 高位持续放量不涨，或下跌带量 |
| 板块 | 龙头震仓时板块有助攻、中军稳住 | 板块集体退潮，龙头孤立补跌 |
| 锚 | 不破锚（5 日线/大阳半分位/分歧日低） | 破锚无承接 |

## 三、有效突破 vs 假突破五维度

| 维度 | 有效突破 | 假突破 |
|---|---|---|
| 位置 | 底部震荡已久或前高充分换手整理后 | 高位突然无量突破、下降途中无量突破 |
| 量能 | 温和放量 1.5~2.5 倍均量，收盘站上前高 | 历史天量长上影，或无量次日回落破位 |
| 收盘质量 | 收盘近最高价，上影线短 | 长上影墓碑线，上影 > 实体 2 倍 |
| 回踩验证 | 回踩缩量不破突破阳半分位 | 回踩破前高或反抽无量再跌 |
| 板块共振 | 同题材跟风助攻或中军同步突破 | 孤立票无板块联动 |

操作：有效突破日极轻仓试错 5%~10%，回踩缩量不破半分位加仓确认。

## 四、分时承接（盘口语言）

- **真承接**（主力主动护盘吸筹）：随板块下杀时缓跌/锯齿状回落，分时低点逐级抬高，两次回踩不破前低，在重要均价线/昨收价横盘筑底；下跌量极度萎缩，拐头拉升时中大单连续吃货。
- **无承接**（诱多出货，坚决规避）：无消息打压却 90 度垂直跳水；买一至买五挂单薄弱被快速扫单下破且不补；反弹无量、下跌带量；均价线随股价同步新低。

## 五、量价六原则（同组合高低位含义相反）

| 组合 | 低位含义 | 高位含义 |
|---|---|---|
| 量增价涨 | 主力启动，可跟进 | 加速赶顶，谨慎 |
| 量缩价涨 | 筹码锁定，等补量 | 虚涨背离，见顶预警不追 |
| 量增价跌 | 恐慌盘涌出或主力挖坑震仓，等企稳 | 主力派发，果断离场 |
| 量缩价跌 | 良性回调，等止跌 | 无人接盘，继续看跌 |
| 量增价平 | 主力温和吸筹，可关注 | 出货前兆（量顶天价不涨），坚决清仓 |
| 量缩价平 | 磨底或方向选择前夕，观望 | 下跌中继，回避 |

实战：等量缩至"地量芝麻点"后再现"倍量红阳"拐头向上时买入。

## 六、四大核心买点

### 1. 波段买点（20 日线拐头）
- 前置：周线月线处于历史底部区域、基本面无雷、排除下降通道；**20 日均线走平拐头向上（向下时任何买点无效）**；5 日线金叉 10 日线或即将金叉。
- 第一买点：底部首根放量突破大阳线确认日，或震仓末端（日内冲高急跌、尾盘带量拉起）逢低介入。
- 第二买点：回踩 10/20 日线缩量止跌收小阳/十字星二次上车。
- 辅助信号：60 分钟 K 线"红肥绿瘦"（红柱多且长、绿柱少且短）= 主力运作。
- 滞后修正：不要等多头排列完美才买；20 日线即将拐头或刚转向上初期介入，赚技术派确认前那段空间。

### 2. 主升首分歧低吸（最优黄金买点）
- 条件：主线空间龙 ≥4~5 板、梯队完整；首次爆量分歧（烂板/尾盘漏单但未断板）；次日不核按钮，低开有承接或平开带量上攻。
- 执行：分歧日尾盘确认承接 → 尾盘低吸；次日弱转强带量翻红 → 半路或打回封。
- 防守位 = 分歧日最低价，破位走人。

### 3. 弱转强
- 标准：昨日烂板/强分歧，次日竞价高开 2%~5%；9:20~9:25 竞价主力坚决吃单；开盘快速上攻带量 → 持股不动或打回封加仓。
- 反面（该强不强则为弱）：昨强板今平开/低开无承接、竞价量能萎缩无人接力 → 竞价或开盘速走，不抱幻想，绝不补仓。

### 4. B 点试错（波段赔率最高低吸点）
- 定义：空头力量耗尽、多头开始主动承接反击的临界区。
- 识别：从近期高点回撤 15%~30% + 成交量极致萎缩（地量）；当日早盘急杀至支撑有大单承接，不破锚或微破瞬时收回，收盘拉回均价线；K 线缩量止跌小阳/十字星，次日放量反包阳或当日长下影阳线。
- 执行：极小仓 5%~10% 试错；防守位 = B 点当日最低价 -0.5%，破位走。

### 附：涨停缩量回踩战法（五步）
1. 筛选：主线/潜在主线内有地位的票（先锋/龙/核心老龙），早盘牢固封板；
2. 观察回踩：次日~3 日内缩量回踩不破涨停阳半分位（强票不破开盘价）；
3. 等止跌 K 线：缩量小阳/十字星，不急当天买；
4. 试错买：止跌后再放量上穿 5 日线或突破小平台 → 轻仓 5%~10%；
5. 防守 = 止跌 K 线最低价 -5%，破支撑走人，禁止补仓。
禁忌：退潮期不用此法（假支撑后补跌）；不用尾盘偷袭板/烂板做样本；只做主线核心票。

## 七、卖点与止损信号

**无条件止损铁律**：亏 50% 需涨 100% 回本；单笔 -5%~-7% 触发无条件砍仓；破锚（分歧日最低/大阳半分位/5 日线）立即走；买入逻辑消失（如 20 日线拐头向下）无条件出；严禁死扛、严禁补仓摊成本。"炸板秒割不眨眼、认错走人重新来。"

**移动保本**：盈利后止损上移到成本价上方，永不让盈利变亏损。

**三级减仓/清仓信号**：
1. 警戒减仓：加速上涨偏离均线过远、巨量长上影、板块后排掉队 → 减半仓或去弱留强；
2. 明确减仓/止盈：有效跌破 10 日线反抽无力、爆量不涨、空间龙被核 → 清剩余仓位；
3. 彻底清仓：有效破 20 日线趋势线、跌破启动阳线 1/2 → 全清，波段结束。

**高位出货信号**：高位放量滞涨（量顶天价不涨）；长上影/墓碑线/高开低走大阴；利好公布日不涨反跌或冲高回落；底部筹码峰完全消失、高位形成密集峰。

**预期管理**（持仓校验）：
- 超预期：昨烂板今竞价高开 3%+ 带量快速上攻 → 持股或打回封加仓；
- 符合预期：强板次日 1%~3% 溢价或分歧后平开震荡换手 → 看分时流畅度持股或分批止盈；
- 不及预期：极端强板次日平开/低开闷杀、板块大涨它独弱、竞价量缩无人接力 → 竞价或开盘速走。
