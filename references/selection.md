# 选股体系：主线确认与个股角色定位

> 同板块只做龙头/先锋/核心中军。无主线思维买杂毛跟风，是散户亏损五大根源之一。

## 一、主线确认五步法

核心板块口诀：**有高度、有宽度、有深度、有回流**。

| 步骤 | 动作 | 确认标准 |
|---|---|---|
| 1 看消息级别 | 评估催化等级 | 国家级战略/重磅会议点名/重大事件催化，想象空间大 |
| 2 看首日异动 | 开盘 30~60 分钟观察 | 密集首板潮，同题材涨停 >3~5 家；板块指数带量突破前高；非个股庄股行为（孤立首板降级观察） |
| 3 看容量中军 | 找板块内百亿市值趋势大票 | 中军高开高走放量大阳助攻 = 机构游资共振；只有小票乱炒、中军走弱 = 一日游 |
| 4 看老龙异动 | 查上一轮同题材人气老龙 | 老龙底部率先堆量止跌、温和放量突破压力线或拉首板 = 资金回流风向标；老龙不动 → 一日游概率大 |
| 5 次日溢价验证 | 次日确认 | 空间龙候选高溢价、首板活口留存率高、中军无负反馈 → 主线地位确认，聚焦核心 |

盘中动态补充：首次分歧后资金回流做反包/补涨、大盘下跌时板块抗跌 → 主线质量高。

## 二、个股角色体系与操作方式

| 角色 | 定义/硬指标 | 买点 | 锚定点/离场 |
|---|---|---|---|
| **空间龙**（真龙头） | 三硬指标同时满足：① 当前周期连板最高（或并列最高但带动性更强）② 板块助攻（小弟跟涨跟跌，非孤立庄股）③ 情绪标杆（一字/弱转强/分歧回封气质，资金认可度高） | 主升首次良性大分歧低吸；弱转强确认 | 锚 = 分歧日最低价，破则走 |
| **中军** | 百亿+市值，机构游资共振，沿均线温和上行 | 首阳启动；回踩 10/20 日线缩量企稳低吸 | 破 20 日线走 |
| **补涨龙** | 龙头打出高度后低位启动；高度 ≤ 龙头的 50%~70%；无独立带动性 | 极小仓试错或放弃 | 快进快出；真龙 A 字杀时立即清仓 |
| **穿越龙** | 旧周期退潮逆势抗跌、扛过冰点不死；新周期启动日率先最强领涨 | 新周期共振日弱转强打板，空间极大 | 掉队 = 假穿越，立即离场 |
| **老龙头** | 上一轮同题材市场合力选出的总龙头（一般 ≥5 板，有板块带动性、资金记忆） | 启动试错：底部温和放量站上 5 日线极小仓；确认加仓：首板或反包阳+板块 ≥2 只助攻；二波：放量突破前高+梯队配合 | 只做右侧确认，不接下跌飞刀；前高附近爆量不板不追 |

老龙三大作用：① 新题材温度计（老龙动→行情质量高）；② 反抽/二波锚定（调整到重要支撑缩量止跌+消息二次点火）；③ 退潮期抱团载体（无新题材时活跃资金抱团做记忆反抽）。

## 三、真龙头 vs 补涨龙速查

| 维度 | 真龙头 | 补涨龙 |
|---|---|---|
| 启动时间 | 题材最早首板走出 | 真龙打出高度后低位启动 |
| 板块带动性 | 有（它涨小弟跟、它分歧小弟抗） | 无/弱，真龙倒它先 A |
| 高度预期 | 情绪上限，最高板 | ≤ 真龙 50%~70% |
| 分歧承接 | 首次分歧有承接不 A | 分歧易直接核，承接弱 |
| 退潮表现 | 横盘震荡或 A 字（视周期） | 直接 A 字杀无反抽 |

**操作铁律**：主升期专注真龙不做补涨；补涨缩量加速 2~3 板不追；真龙 A 字杀时补涨立即清仓。

## 四、首次良性分歧（黄金买点）的确认条件

强主线总龙头第一波连板中途，首次高潮导致爆量烂板/爆量首阴/尾盘漏单，**且**：板块未全灭、无连续跌停核按钮；首次大震仓尾盘或次日不再低开低走、分时企稳（弱转强带量上攻翻红）= 超短确定性最高的低吸买点。

## 五、审美标准（选股质检清单）

审美 = 识别资金质量、题材质量、个股地位的能力。
- 每天翻涨幅榜前 50 + 涨停复盘，标记龙头/中军/跟风；
- 记录买过的杂毛票及亏损原因，建"不买清单"；
- 行情差时空仓，不降低标准；
- 看懂资金介入信号（堆量、板块联动、老龙异动）第一时间试错——等加速高潮再去 = 审美不够。

K 线心法：**K 线只是结果，资金意图 + 情绪周期 + 板块地位才是原因。**
