# 情绪周期：五阶段判定与仓位动作

> 情绪周期是所有题材的母体。先判周期，再定仓位，最后才谈个股。

## 一、五阶段量化判定表

| 阶段 | 盘面量化标准 | 总仓位 | 动作基调 |
|---|---|---|---|
| **冰点期**（混沌磨底） | 连板高度压制在 2~3 板内；跌停 ≥10~20 家；核按钮频现（昨涨停今跌停） | 0 或 ≤5% | 空仓观望，只盯自选池异动；唯一动作：跌停骤减、高度止跌的转折点，极轻仓试错新题材破冰首板 |
| **启动期**（新周期确立） | 旧主线退潮；新题材有重磅政策/事件催化；首日批量首板潮（同题材 ≥2~5 只涨停）；老龙止跌 | 5%~10% | 轻仓试错模式内最先封板先锋或一进二换手板；不抢无板块效应的冷门票 |
| **主升期**（黄金进攻窗口） | 空间龙走出 ≥4~5 板辨识度；梯队完整（空间龙+中位晋级+低位补涨）；百亿市值中军放量助攻；首分歧有承接 | 20%~40%，单票 ≤50% | 黄金出手期敢于推仓：围绕真龙头做首次良性大分歧低吸、或弱转强确认 |
| **高潮期**（盛极而衰预警） | 板块批量涨停；后排垃圾股补涨全红；中位票缩量加速秒板；自媒体狂吹；场外惜售买不进核心 | 持有或减至 20%~30% | 持仓者盛宴、持币者禁区；绝不追高；去弱留强分批减仓锁利润 |
| **退潮期**（全面杀跌） | 龙头爆量断板/被核按钮；A 字杀不反包；中位股成排跌停；亏钱效应扩散（面率 >30%）；老龙补跌 | **0，空仓** | 无条件清仓，停止一切低吸打板，等新冰点；不幻想二波重仓 |

节奏口诀：**冰点试错 → 启动确认加 → 主升做分歧 → 高潮减 → 退潮空仓**

## 二、四大关键节点（非节点日不新建重仓）

1. **冰点节点**：退潮末端跌停收敛、核按钮减少 → 空仓等信号，盯首板试错。唯一低风险窗口。
2. **启动节点**：新题材 ≥2~3 首板、老龙止跌 → 轻仓试错先锋/潜在龙。
3. **主升确认节点（首分歧）**：空间龙 ≥4~5 板后首次爆量烂板/尾板未断 → 黄金上车点，次日低吸或弱转强确认。
4. **退潮节点**：空间龙爆量断板/被核、中位跌停扩散 → 清仓持仓，空仓等下一冰点。

## 三、做多一致性四维度（确认行情质量）

1. **板块效应**：同题材 ≥3~5 只涨停，有先锋+空间板+中军。
2. **龙头表态**：高开/缩量加速/爆量分歧后承接强。
3. **指数与情绪环境**：大盘企稳，连板高度 ≥4 板，跌停 <5 只。
4. **资金流向**：中军温和放量上攻，机构+游资共振。

## 四、过度一致与鱼尾行情（顶部信号，必须识别）

**过度一致特征**：早盘板块大范围一字涨停；龙头百万手封单缩量加速；中位秒板；后排补涨全红；自媒体狂吹目标价。
→ 持仓不追，分批减仓；**尤其不接缩量加速中位票**。

**鱼尾信号**（满足越多越危险）：
- 早盘 ≥3 只一字涨停、龙头缩量加速（题材过度一致）；
- 中位补涨全面启动——此前只有龙头+先锋，突然首板全是低位冷门补涨杂毛；
- 空间龙爆量断板或次日大幅低开被核；
- 舆论过热：抖音/股吧/群刷屏"星辰大海""目标价 XX"。

鱼尾期接力中位股，次日闷杀大面率 >60%。
→ 持仓者分批减仓、断板清仓；空仓者宁可错过，绝不降低审美买跟风伪补涨，等下一冰点。

## 五、周期错配的典型死法（提醒用户用）

- 退潮期猛干接力板 = 接飞刀；
- 主升期恐高不敢上龙头 = 踏空黄金窗口；
- 高潮末端追缩量加速板 = 贪婪接鱼尾、高位站岗；
- 冰点期割在地板上 = 倒在黎明前。
